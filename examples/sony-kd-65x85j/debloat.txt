# Checked on the TV (Wi-Fi):
# - Everything stays disabled and Home stays on the new launcher after `svc power reboot`.
# - setupwraith owned only stale saved networks; the active one belonged to android.uid.system, so
#   FORCE_SETUPWRAITH=1 disabled it with no Wi-Fi drop. If your saved network belongs to it,
#   disable.sh skips it: forget the network on the TV and join it again first.
# - Re-enabling setupwraith hands Home back to its RecoveryActivity; disable it again and run
#   `cmd package set-home-activity --user 0 com.gathin.tvhome/.MainActivity` to recover.
# - launcherx and dreamx disabled only after the new launcher was installed, with the launcher's clock as
#   screensaver: settings put secure screensaver_components com.gathin.tvhome/.ClockDream
# - Screenshots come out empty while Netflix is on screen; press Home first.
# - The remote's Input button was NOT tested on this set (the SA list reports it works via systemui).
# - Launcher config: live_tv_package com.sony.dtv.tvx, hidden apps com.sony.dtv.tvx and the Vewd browser
#   (com.vewd.core.integration.dia).
# Applied and reboot-checked on 21 October 2026, not yet lived with for days. If something breaks,
# re-enable it with `pm enable <package>` and please report it.

# reboot. Bisecting every disabled package back to fully-disabled with clean restarts showed the
